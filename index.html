Which one is easier?

Main manualSeparate handouts (Expt 4–9)
Size1.9 MB, 15 experiments + extras, long theory6 short files, 1–4 pages each
CodeNo program for Hamming code or sliding window (aim + requirements only)Full ready-to-run Python code for ping, FTP scanner, XML-RPC, reverse TCP
StepsGood for cables and Packet Tracer; Wireshark and Nmap are mostly reading materialNumbered procedure, commands and expected output
ToolsPacket Tracer, Wireshark, TryHackMe accountOnly Python (Packet Tracer for Expt 4 and 9)
Best forSyllabus coverage, theory, viva questionsActually running and writing the experiment

Verdict: the separate handouts are easier and simpler – short, complete, and runnable. Use the main manual for the experiments the handouts do not cover (commands, cables, Packet Tracer basics, Wireshark, Hamming, sliding window, Nmap, wireless, subnetting, routers).

Check numbering: the handouts' Expt 5–9 are different experiments from the main manual's Practical 5–9. Follow the experiment list your faculty gave you.
